PRACTICAL 01 — Provide the PEAS description and TASK Environment for a given AI problem.
======================================================================

AIM
To describe an AI problem using the PEAS framework and to classify its task environment.

SHORT THEORY
- An agent is anything that perceives its environment through sensors and acts on it through actuators.
- PEAS = Performance measure, Environment, Actuators, Sensors. It specifies the task the agent must solve.
- Task environment properties:
  Observable      : fully (sensors show complete state) / partially
  Agents          : single agent / multi-agent
  Deterministic   : next state fully decided by current state and action / stochastic
  Episodic        : each action independent of the past / sequential (current action affects future)
  Static          : environment does not change while agent thinks / dynamic
  Discrete        : finite number of states and actions / continuous
- Hardest case (real world): partially observable, multi-agent, stochastic, sequential, dynamic, continuous (e.g. taxi driving).

PROGRAM / DATASET DETAILS
Four AI problems are described: Automated Taxi, Vacuum Cleaner Robot, Medical Diagnosis System, Chess Player. To answer a different problem in the exam, copy one show_peas(...) call and change the values.

HOW TO RUN IN VS CODE
Output is printed in the terminal. No libraries needed.

# Practical 01 - PEAS description and Task Environment

def show_peas(name, performance, environment, actuators, sensors, task_env):
    print("=" * 60)
    print("PROBLEM:", name)
    print("=" * 60)
    print("P - Performance measure :", ", ".join(performance))
    print("E - Environment         :", ", ".join(environment))
    print("A - Actuators           :", ", ".join(actuators))
    print("S - Sensors             :", ", ".join(sensors))
    print("\nTask Environment properties:")
    for prop, value in task_env.items():
        print("  {:<14}: {}".format(prop, value))
    print()
