PRACTICAL 08 — Implementation of Naïve Bayes Classifier for a given example data set.
======================================================================

AIM
To classify Iris flowers into species using the Gaussian Naive Bayes classifier.

SHORT THEORY
- Naive Bayes is a probabilistic classifier based on Bayes' theorem:  P(Class | X) = P(X | Class) * P(Class) / P(X).
- 'Naive' because it assumes all features are independent of each other given the class.
- Prediction = class with the highest posterior probability.
- GaussianNB is used for continuous features: each feature of each class is modelled by a normal distribution (mean, variance).
- Advantages: simple, fast, works well with small data and text classification. Disadvantage: independence assumption is rarely true.

PROGRAM / DATASET DETAILS
Iris dataset (built into scikit-learn): 150 flowers, 4 features, 3 classes. Split 70% training / 30% testing.

# Practical 08 - Naive Bayes Classifier
# Dataset: Iris (built into scikit-learn, no download needed)
import numpy as np
import matplotlib.pyplot as plt
import seaborn as sns
from sklearn.datasets import load_iris
from sklearn.model_selection import train_test_split
from sklearn.naive_bayes import GaussianNB
from sklearn.metrics import accuracy_score, confusion_matrix, classification_report

# 1. Load data
iris = load_iris()
X = iris.data
y = iris.target
print("Features:", iris.feature_names)
print("Classes :", iris.target_names.tolist())

# 2. Split into training (70%) and testing (30%)
X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.3, random_state=42, stratify=y)
print("Training samples:", len(X_train), "| Testing samples:", len(X_test))

# 3. Train the Gaussian Naive Bayes model
model = GaussianNB()
model.fit(X_train, y_train)
print("\nClass prior probabilities:", model.class_prior_.round(3))

# 4. Predict on test data
y_pred = model.predict(X_test)
print("Actual    :", y_test[:15])
print("Predicted :", y_pred[:15])

# 5. Evaluate
print("\nAccuracy:", round(accuracy_score(y_test, y_pred), 4))
print("\nConfusion Matrix:")
print(confusion_matrix(y_test, y_pred))
print("\nClassification Report:")
print(classification_report(y_test, y_pred, target_names=iris.target_names))

# 6. Predict a new flower
new_flower = [[5.1, 3.5, 1.4, 0.2]]
pred = model.predict(new_flower)[0]
proba = model.predict_proba(new_flower)[0]
print("New flower", new_flower[0], "-> predicted class:", iris.target_names[pred])
print("Probabilities:", {str(n): round(float(p), 4) for n, p in zip(iris.target_names, proba)})

# 7. Confusion matrix plot
sns.heatmap(confusion_matrix(y_test, y_pred), annot=True, cmap="Blues",
            xticklabels=iris.target_names, yticklabels=iris.target_names)
plt.xlabel("Predicted")
plt.ylabel("Actual")
plt.title("Naive Bayes - Confusion Matrix")
plt.show()
----- CODE END -----
