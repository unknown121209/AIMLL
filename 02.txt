PRACTICAL 02 — Write simple programs using PROLOG as an AI programming Language.
======================================================================

AIM
To write simple Prolog programs using facts, rules, arithmetic, recursion and lists.

SHORT THEORY
- Prolog is a declarative (logic) programming language used in AI. We state facts and rules; Prolog finds the answer by itself.
- Fact: parent(john, mary).   Rule: grandparent(X,Z) :- parent(X,Y), parent(Y,Z).   (:- means IF, comma means AND)
- Query: ?- father(john, X).   Prolog searches the knowledge base using unification and backtracking.
- Variables start with a capital letter (X, Y); constants/predicates start with a small letter.
- Lists are written [a,b,c]; [H|T] splits a list into Head and Tail. Recursion is used instead of loops.
- Arithmetic uses  is :   N1 is N - 1.

PROGRAM / DATASET DETAILS
Programs included: hello world, family tree (father, mother, grandparent, sibling), maximum of two numbers, even number, factorial, Fibonacci, list length, list sum, list append, list membership.

HOW TO RUN IN VS CODE
1. Install SWI-Prolog from https://www.swi-prolog.org/download/stable (tick 'add to PATH' during install).
2. In VS Code create a file practical02.pl and paste the code below (optional extension: 'VSC-Prolog').
3. Open the VS Code terminal and run:   swipl practical02.pl
   The demo runs automatically (initialization(main)) and then the  ?-  prompt appears.
4. Type your own queries at the ?- prompt (each ends with a full stop):
      ?- father(john, X).          gives  X = mary ;  X = tom.     (press ; for next answer)
      ?- grandparent(john, Z).     gives  Z = ann ;  Z = bob.
      ?- factorial(6, F).          gives  F = 720.
      ?- max_of(7, 3, M).          gives  M = 7.
      ?- my_append(X, Y, [1,2]).   gives all ways of splitting the list.
      ?- my_member(b, [a,b,c]).    gives  true.
   Type  halt.  to exit.

CODE (copy everything between the START and END lines)
----- CODE START (save as practical02.pl) -----
% Practical 02 - Simple programs in PROLOG
% Save as practical02.pl   |   Run in terminal:  swipl practical02.pl

% ---------- 1. Hello World ----------
hello :- write('Hello, welcome to AI programming with Prolog!'), nl.

% ---------- 2. Facts and Rules (Family tree) ----------
parent(john, mary).
parent(john, tom).
parent(mary, ann).
parent(mary, bob).

male(john).
male(tom).
male(bob).
female(mary).
female(ann).

father(X, Y)      :- parent(X, Y), male(X).
mother(X, Y)      :- parent(X, Y), female(X).
grandparent(X, Z) :- parent(X, Y), parent(Y, Z).
sibling(X, Y)     :- parent(P, X), parent(P, Y), X \= Y.

% ---------- 3. Arithmetic ----------
max_of(X, Y, X) :- X >= Y.
max_of(X, Y, Y) :- X < Y.

even(N) :- 0 is N mod 2.

factorial(0, 1).
factorial(N, F) :- N > 0, N1 is N - 1, factorial(N1, F1), F is N * F1.

fib(0, 0).
fib(1, 1).
fib(N, F) :- N > 1, A is N - 1, B is N - 2, fib(A, FA), fib(B, FB), F is FA + FB.

% ---------- 4. Lists ----------
my_member(X, [X|_]).
my_member(X, [_|T]) :- my_member(X, T).

my_length([], 0).
my_length([_|T], N) :- my_length(T, N1), N is N1 + 1.

my_sum([], 0).
my_sum([H|T], S) :- my_sum(T, S1), S is S1 + H.

my_append([], L, L).
my_append([H|T], L, [H|R]) :- my_append(T, L, R).

% ---------- Demo: runs automatically ----------
main :-
    hello,
    write('--- Family ---'), nl,
    forall(father(X, Y), (write(X), write(' is father of '), write(Y), nl)),
    forall(grandparent(X, Y), (write(X), write(' is grandparent of '), write(Y), nl)),
    forall(sibling(X, Y), (write(X), write(' and '), write(Y), write(' are siblings'), nl)),
    write('--- Arithmetic ---'), nl,
    max_of(10, 25, M), write('Max of 10 and 25 = '), write(M), nl,
    factorial(5, F), write('Factorial of 5 = '), write(F), nl,
    fib(7, FB), write('Fibonacci(7) = '), write(FB), nl,
    ( even(8) -> write('8 is even') ; write('8 is odd') ), nl,
    write('--- Lists ---'), nl,
    my_length([a, b, c, d], Len), write('Length = '), write(Len), nl,
    my_sum([1, 2, 3, 4, 5], S), write('Sum = '), write(S), nl,
    my_append([1, 2], [3, 4], L), write('Append = '), write(L), nl,
    ( my_member(c, [a, b, c]) -> write('c is a member') ; write('c is not a member') ), nl.

:- initialization(main).
