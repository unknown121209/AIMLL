PRACTICAL 07 — Implementation of Principal Component Analysis for a given example data set.
======================================================================

AIM
To reduce the dimensions of the Iris dataset from 4 features to 2 using Principal Component Analysis (PCA).

SHORT THEORY
- PCA is a dimensionality reduction technique. It converts correlated features into new uncorrelated features called principal components (PCs).
- PC1 is the direction of maximum variance in the data, PC2 is the next direction of maximum variance perpendicular to PC1, and so on.
- Steps: standardize data -> compute covariance matrix -> find eigenvalues/eigenvectors -> sort by eigenvalue -> keep top k components -> project data.
- Explained variance ratio tells how much information each component keeps.
- Uses: visualization, noise reduction, faster training, removing multicollinearity.

PROGRAM / DATASET DETAILS
Iris dataset: 150 flowers, 4 features (sepal length/width, petal length/width), 3 species. It is built into scikit-learn (no download).

HOW TO RUN IN VS CODE

Save the code as 07.py and run:   python 07.py

# Practical 07 - Principal Component Analysis (PCA)
# Dataset: Iris (150 flowers, 4 features) - built into scikit-learn, no download needed
import numpy as np
import pandas as pd
import matplotlib.pyplot as plt
from sklearn.datasets import load_iris
from sklearn.preprocessing import StandardScaler
from sklearn.decomposition import PCA

# 1. Load data
iris = load_iris()
X = iris.data
y = iris.target
df = pd.DataFrame(X, columns=iris.feature_names)
print("Original data shape:", X.shape)
print(df.head())

# 2. Standardize the data (PCA needs features on the same scale)
X_scaled = StandardScaler().fit_transform(X)

# 3. Apply PCA with all components to see the variance of each
pca_all = PCA()
pca_all.fit(X_scaled)
print("\nExplained variance ratio of each component:")
for i, ratio in enumerate(pca_all.explained_variance_ratio_):
    print("  PC{} = {:.4f}  ({:.1f}%)".format(i + 1, ratio, ratio * 100))
print("Cumulative variance:", np.cumsum(pca_all.explained_variance_ratio_).round(4))

# 4. Reduce 4 features to 2 principal components
pca = PCA(n_components=2)
X_pca = pca.fit_transform(X_scaled)
print("\nReduced data shape:", X_pca.shape)
print("First 5 rows after PCA:")
print(X_pca[:5].round(3))
print("Variance kept by 2 components: {:.1f}%".format(pca.explained_variance_ratio_.sum() * 100))

# 5. Plot the 2D result
plt.figure(figsize=(7, 5))
for label, name in enumerate(iris.target_names):
    plt.scatter(X_pca[y == label, 0], X_pca[y == label, 1], label=name)
plt.xlabel("Principal Component 1")
plt.ylabel("Principal Component 2")
plt.title("PCA of Iris Dataset")
plt.legend()
plt.show()
